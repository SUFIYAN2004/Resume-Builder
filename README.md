🚀 Resume Builder – Final Year Project

A modern, web-based Resume Builder that allows users to create professional resumes using multiple templates, with support for fresher and experienced candidates. The application focuses on clean UI/UX, ATS-friendly layouts, live preview, and downloadable resumes — built entirely using HTML, CSS, JavaScript, and Bootstrap 5.

✨ Features

🎯 Separate resume flow for Freshers and Experienced professionals

🎨 Premium template selector with modern UI

🔁 Switch between multiple resume templates

👀 Live resume preview

📄 Download resume as PDF

💾 Persistent data using localStorage

🧾 ATS-friendly and clean resume layouts

📱 Fully responsive design

⚡ Fast, lightweight, and free to use

🛠️ Tech Stack

Frontend: HTML5, CSS3, JavaScript (ES6)

UI Framework: Bootstrap 5

Styling: Custom CSS + Modern UI principles

State Management: Browser localStorage

PDF Generation: Browser print / PDF export

🧠 Project Highlights

Modular and scalable frontend architecture

User-centric design with visual template selection

Production-level UI/UX enhancements

Designed as a real-world SaaS-style application

Ideal for academic submission and entry-level portfolios
